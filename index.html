Formal Automata Theory & Mathematical Proof

Formal definition of 5-tuple M = (Q, Σ, δ, q0, F) and Viva Reference

Formal 5-Tuple Definition

M = (Q, Σ, δ, q0, F)

  • Q = Finite set of all composite configurations (Floor × Door × Direction × Requests × Mode). Total reachable states: >1,500 finite configurations.
  • Σ = { U, D, O, C, T, E, R, REQ_CABIN_1..4, REQ_HALL_1..3_UP, REQ_HALL_2..4_DOWN } (17 discrete input symbols).
  • q0 = (Floor 1, CLOSED, IDLE, ∅, NORMAL) — Initial Ground Configuration.
  • F = All safe operational states where Mode = NORMAL.
  • δ: Q × Σ → Q — Total, deterministic transition function implementing SCAN collective scheduling.

Viva Explanation: Why is this still a DFA?

Formal Proof: Although the simulator supports realistic multi-request scheduling and simultaneous users, the state space is strictly finite because:

Finite Domains Floors (4) × Doors (2) × Directions (3) × Request Subsets (210 = 1024) × Modes (2) = Finite bounded set.
Determinism For every state q ∈ Q and every symbol σ ∈ Σ, there exists exactly one next state δ(q, σ).
No Deadlocks Boundary inputs (e.g. Floor 4 + UP) and door-open movement attempts execute safe self-loops rather than crashing into dead states.
